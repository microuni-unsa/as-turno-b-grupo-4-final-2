## Mandato Operativo de Inspección Visual (HOW TO SEE)

> [!IMPORTANT]
> **PROHIBICIÓN ESTRICTA DE EXTRACCIÓN DE TEXTO CIEGA**  
> Queda terminantemente prohibido para cualquier agente o desarrollador downstream tomar texto plano extraído como única fuente de diseño de los moldes. Antes de crear o editar cualquier archivo en `molds/`, el trabajador **DEBE abrir e inspeccionar visualmente los archivos `.png`** en su entorno de trabajo para verificar distribución, jerarquías, anchos de columna de tablas, encabezados de doble nivel y bloques de firma.

### Comandos de Reproducción Idéntica
Cualquier trabajador puede verificar o reproducir este corpus utilizando los siguientes comandos estándar:

```bash
# 1. Conversión de Word (.docx) a PDF:
soffice --headless --convert-to pdf --outdir <slug_dir> docs/templates/<archivo>.docx

# 2. Conversión de Excel (.xlsx) a PDF con una página por hoja:
soffice --headless --convert-to "pdf:calc_pdf_Export:{\"SinglePageSheets\":{\"type\":\"boolean\",\"value\":\"true\"}}" --outdir <slug_dir> docs/templates/<archivo>.xlsx

# 3. Renderizado de páginas PDF a PNG a 150 DPI:
uv run --with pymupdf python -c "
import fitz
doc = fitz.open('<slug_dir>/source.pdf')
for i, page in enumerate(doc):
    pix = page.get_pixmap(dpi=150)
    pix.save(f'<slug_dir>/p{i+1:02d}.png')
"
```
